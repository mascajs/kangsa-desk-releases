# 강사데스크 (Windows)

프리랜서 강사를 위한 바탕화면 앱 — 구글 캘린더의 강의 일정, 회차, 수업 준비 할 일, 서류 마감, 수업 링크·QR, 메모를 바탕화면에 보여 줍니다.

## 설치
1. [Releases](../../releases/latest)에서 `kangsa-desk-버전-setup.exe`를 받아 실행합니다.
2. "Windows의 PC 보호"가 뜨면 **추가 정보 → 실행**을 누릅니다 (코드 서명을 하지 않은 앱이라 뜹니다).
3. 처음 실행하면 설정 마법사가 뜹니다 (구글 로그인 → 테마 → 화면 → 날씨 → 바로가기 → 백업·동기화).

설치한 뒤에는 새 버전이 나오면 앱이 알아서 받아 두고, "새 버전 적용 (다시 시작)"을 누르면 적용됩니다.

## 데이터
- 일정은 구글 캘린더에서 읽기만 합니다.
- 메모·할 일·서류 등은 이 PC와 사용자 본인의 구글 드라이브('강사데스크 백업' 폴더)에만 저장됩니다. 개발자 서버는 없습니다.
