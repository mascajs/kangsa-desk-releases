# 강사데스크 사용 안내 (Windows)

프리랜서 강사를 위한 바탕화면 앱입니다. 구글 캘린더의 강의 일정을 읽어 **오늘 수업, 회차, 수업 준비 할 일, 서류 마감, 수업 링크·QR, 메모**를 바탕화면에 한눈에 보여 줍니다.

- 일정은 구글 캘린더에서 **읽기만** 합니다(고치거나 지우지 않음).
- 메모·할 일·서류 같은 자료는 **이 PC와 본인 구글 드라이브**에만 저장됩니다. 개발자 서버는 없습니다.

---

## 1. 설치

1. [Releases](../../releases/latest)에서 `kangsa-desk-버전-setup.exe`를 받아 실행합니다.
2. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (코드 서명을 하지 않은 앱이라 뜨는 경고입니다)
3. 설치가 끝나면 바로 실행되고, 바탕화면에 "강사데스크" 바로가기가 생깁니다.

**업데이트**: 설치한 뒤에는 새 버전이 나오면 앱이 알아서 받아 둡니다. 화면 오른쪽 아래(또는 트레이 메뉴)에 **"새 버전 적용 (다시 시작)"**이 보이면 누르세요. 누르기 전까지는 다시 시작하지 않습니다.

## 2. 처음 설정 (마법사)

처음 설치하면 설정 마법사가 뜹니다. 단계마다 **건너뛰기**가 되고, 나중에 설정(⚙)에서 모두 바꿀 수 있습니다.

1. **구글 연결** — [구글로 로그인] → 브라우저에서 계정 선택 → 캘린더 읽기 허용.
   - **"Google에서 확인하지 않은 앱"** 경고가 뜨면 왼쪽 아래 **고급 → 강사데스크(으)로 이동(안전하지 않음)**을 누릅니다. 개인 개발 앱이라 구글 심사를 아직 받지 않아 뜨는 화면이며, 앱은 캘린더를 읽기만 합니다.
2. **색 테마** — 라벤더 · 민트 · 핑크 · 아이보리 · 스카이블루
3. **화면** — 바탕화면 위젯 / 일반 창, 카드 사이 배경 채우기, 컴퓨터 켤 때 자동 실행, (모니터가 둘 이상이면) 뜰 모니터
4. **날씨 지역** — "○○시 ○○구"처럼 시·구 이름으로 찾기
5. **바로가기** — 화면 아래 바로가기 줄 쓰기와 넣을 바로가기
6. **백업·동기화** — [드라이브 백업 연결]

## 3. 캘린더에 강의 적는 법 (중요)

앱은 일정 **제목**을 읽어 강의인지 알아봅니다. 아래 중 하나라도 맞으면 강의로 봅니다.

| 제목 예 | 읽는 법 |
|---|---|
| `A중 코딩 주강 (가나에듀)` | 출강처 **A중** · 프로그램 **코딩** · 역할 **주강** · 파트너사 **가나에듀** |
| `B초 코딩주강` | 역할을 붙여 써도 됨 (`코딩` + `주강`) |
| `C중 코딩주강 다라연구소` | 파트너사 목록에 있는 이름이면 괄호 없이도 파트너사로 읽음 |
| `D초 4-2, 4-4 로봇 보조(마바교육)` | `4-2, 4-4` 같은 반 번호는 따로 떼어 냄 |
| `E고 진로특강` | 첫 단어가 **초·중·고·대·학교·센터·청** 등으로 끝나면 강의 |

- **역할 단어**: `주강`, `보조강`, `보조`, `단독`
- 강의가 아닌 일정(여행, 생일, 내가 듣는 연수 등)은 **개인 일정**으로 연하게 보입니다. 숨기려면 설정의 "개인 일정 흐리게 보기"를 끕니다.
- **잘못 알아본 일정**은 달력의 칩을 **우클릭** → "강의로 표시" / "강의 아님으로 표시". "강의로 표시"를 하면 그 **출강처 이름을 기억**해서 다음부터 같은 출강처 일정은 자동으로 강의로 봅니다.
- **회차**는 같은 출강처 + 프로그램 일정을 날짜순으로 세어 자동으로 붙습니다(최근 180일).

## 4. 화면 구성

| 카드 | 하는 일 |
|---|---|
| **시계·날씨** | 시각, 기본 지역 날씨. 오늘 수업이 있으면 **출강지 날씨**를 아래 줄에 함께 |
| **지금 이 시간** | 수업 중이면 진행 막대와 남은 시간, 아니면 다음 수업까지 남은 시간. 아래에 **오늘 일정 전체**(강의+개인)와 빨간 "지금" 선 |
| **오늘·내일 강의** | 오늘·내일 강의, 끝남/진행 중/예정, ★ = 주강·단독 |
| **달력** | 이번 달 강의 칩(출강처별 색), 개인 일정(점선), 칸에 다 안 들어가면 `+N` |
| **밀린 서류** | 마감이 지났거나 14일 안에 다가온 안 낸 서류 |
| **마감·D-Day** | 직접 넣는 마감(+ 버튼) |
| **할 일** | 수업 준비 할 일이 자동으로 올라옴 |
| **메모** | 포스트잇 쪽지 |

## 5. 역할(주강·보조·단독)과 수업 준비 할 일

- 제목에 역할이 없으면 칩에 **"역할?"**이 붙습니다. 칩 우클릭 → **"이 출강은 주강/보조/단독"** → 그 출강의 모든 회차에 적용됩니다.
- **수업 준비 할 일이 자동으로** 올라옵니다(출강마다 다음 회차 하나만).
  - 주강·단독: 수업 **7일 전**부터 보임, 마감은 수업 전날
  - 보조: 수업 **전날** 보임
  - 일수는 설정의 "수업 준비 할 일"에서 바꿉니다.
- 자동 할 일을 ✕로 지우면 그 회차는 다시 만들지 않습니다.

## 6. 수업 링크 · QR · 회차 메모

- 달력의 강의 칩 **우클릭 → "수업 링크 · 회차 메모"**
  - **수업 링크**: 패들렛, 수업 홈페이지 등 주소 추가(그 출강의 모든 회차 공통). `padlet.com/...`처럼 https 없이 적어도 됩니다.
  - **N회차 메모**: 그 회차 수업 날 "지금 이 시간" 카드에 보입니다(예: 2회차 칸에 "1회차는 4차시까지 진행"을 적어 두면 2회차 날 보임).
- **지금 이 시간** 카드(수업 중이거나 오늘 다음 수업이 있을 때)
  - **▶ 강의 시작**: 등록한 링크를 한꺼번에 브라우저로 엽니다(숫자 = 링크 수).
  - **QR**: 교실 화면용 큰 QR. 링크가 여럿이면 위에서 고르고, Esc로 닫습니다.
  - **✎**: 링크·메모 창 열기

## 7. 서류

- **밀린 서류** 카드의 네모를 누르면 "냈음"으로 사라집니다. 되돌리기는 강의 칩 우클릭 → "수업 링크 · 회차 메모" → **이 출강 서류**에서.
- 서류는 세 군데 규칙을 합쳐 만듭니다(같은 이름은 하나로).
  1. **학교 기본**: 초·중·고 출강 → `범죄경력회보서`(사전, [발급 사이트] 버튼)
  2. **파트너사 규칙**: 설정 → **파트너사·서류 관리** → 업체 고르기 → 서류 이름·단계·누가·일수 → **저장**
  3. **출강 건 규칙**: 강의 칩 우클릭 → "수업 링크 · 회차 메모" → **이 출강에만 필요한 서류** → 저장
- **단계와 마감 기본값**(설정에서 변경)
  - 사전: 첫 회차 7일 전 · 진행: 회차마다 수업 날 · 사후: 마지막 회차 7일 뒤 · 입금: 마지막 회차 30일 뒤
  - 규칙마다 일수를 따로 넣을 수 있습니다(예: "보조 강사에게 사진 요청" 사후 1일).
- **누가**: 모두 / 주강·단독 / 보조 — 그 출강에서의 내 역할에 맞는 서류만 보입니다.
- **"이 날짜부터의 서류만 보기"**(설정): 그보다 마감이 이른 서류는 숨깁니다.
- 파트너사는 **줄여 쓰는 이름**을 넣어 두면(예: 가나에듀 = 가나) 캘린더 제목에 줄임말로 적어도 알아봅니다.

## 8. 메모 · D-Day

- **메모**: 색 고르고 **+ 쪽지** → 눌러서 쓰기(손글씨체) → 위쪽 ⠿ 잡고 끌어 옮기기 → 오른쪽 아래 모서리로 크기 조절 → 위쪽 ✕로 지우기
- **마감·D-Day**: + → 제목·날짜 → 추가. 줄에 마우스를 올리면 ✕

## 9. 바탕화면에서 쓰기

- **숨기기**: 오른쪽 위 **◐** 또는 **Win+D** → 바탕화면 아이콘을 씁니다. 다시 보려면 **작업표시줄의 강사데스크 아이콘**(또는 시계 옆 트레이 아이콘)을 누릅니다.
- **배경 채우기**(설정 → 화면 방식): 켜면 카드 사이가 테마 색으로 채워지고, 끄면 바탕화면 그림·아이콘이 보이고 카드 사이 빈 곳의 아이콘을 누를 수 있습니다.
- **카드 배치 바꾸기**: 오른쪽 위 **✎** → 카드를 끌어 옮기고, 오른쪽 아래 모서리로 크기 조절 → **완료**(또는 Esc). **원래대로**로 되돌릴 수 있습니다. 배치는 노트북마다 따로 저장됩니다.
- **뜰 모니터**(설정): 듀얼 모니터면 고릅니다. 모니터를 빼면 주 모니터로 옮겨집니다.
- **트레이 메뉴**(시계 옆 아이콘 우클릭): 앞으로 보기 · 새로고침 · 위젯/창 모드 · 컴퓨터 켤 때 실행 · 종료. 창을 닫아도 꺼지지 않고 트레이에 남습니다.

## 10. 아래쪽 바로가기 줄

설정 → **아래쪽 바로가기** → "바로가기 줄 쓰기"
- 추천(구글 드라이브, Gmail, 구글 캘린더, ChatGPT, Claude, Gemini, Perplexity, NotebookLM, 캔바, 패들렛, 유튜브, 네이버)
- 사이트 직접 넣기(이름 + 주소)
- 내 PC 프로그램(카카오톡 등 `.exe`나 바로가기 `.lnk`)
- ↑↓로 순서, ✕로 빼기. 끄면 아래 카드들이 넉넉해집니다.

## 11. 백업과 노트북 여러 대

- 설정 → 백업 → **드라이브 백업 연결**(처음 한 번 드라이브 권한 허용). 이 앱이 만든 파일만 볼 수 있는 권한입니다.
- **자동 백업**: 하루 한 번 내 드라이브의 **'강사데스크 백업'** 폴더에 날짜별 파일, 최근 14개 보관. [지금 백업]도 됩니다.
- **복원**: [드라이브에서 복원] → 날짜 → 되돌리기 (지금 데이터는 이 PC에 따로 남겨 둠)
- **노트북 간 동기화**: 같은 구글 계정이면 메모·할 일·D-Day·서류·수업 링크·회차 메모·역할·설정이 **자동으로 맞춰집니다**(바꾸고 몇 초 뒤, 5분마다). [지금 맞추기]도 있습니다.
  - 화면 모드·배경 채우기·자동 실행·바로가기·카드 배치·모니터는 노트북마다 따로입니다.
  - 같은 항목을 두 노트북에서 동시에 고치면 나중에 맞춘 쪽이 남습니다(지움 vs 고침이면 고친 내용이 남음).
- 새 노트북: 설치 → 같은 구글 계정 로그인 → 드라이브 백업 연결 → 몇 분 안에 내용이 들어옵니다.

## 12. 자주 묻는 질문

- **"스마트 앱 컨트롤이 안전하지 않을 수 있는 앱을 차단했습니다"가 떠서 설치가 안 돼요** → 아직 코드 서명을 하지 않은 앱이라, 새 PC에서 켜져 있는 '스마트 앱 컨트롤'이 막는 것입니다. 이 화면에는 넘기는 버튼이 없습니다. 설치하려면 Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기가 필요한데, **끄면 다시 켜기 어려우니** 신중히 결정하세요. 서명된 버전이 나오면 끄지 않아도 설치됩니다.
- **바탕화면 아이콘이 안 눌려요** → ◐(또는 Win+D)로 숨기거나, 설정에서 "카드 사이를 배경색으로 채우기"를 끄세요.
- **로그인이 풀렸어요** → 로그인 카드의 [구글로 로그인]을 다시 누르세요. (2026년 11월 14일 이전에 로그인했다면 한 번 다시 로그인해야 할 수 있습니다)
- **'액세스 차단됨'·'승인되지 않음'으로 로그인이 안 돼요** → 최신 버전인지 확인하고, 경고 화면에서 **고급 → 이동**을 눌렀는지 확인하세요. 계속 안 되면 [GitHub 이슈](https://github.com/mascajs/kangsa-desk-releases/issues)로 알려 주세요.
- **강의가 개인 일정으로 보여요** → 칩 우클릭 → 강의로 표시. 또는 제목에 역할(`주강`)이나 파트너사를 붙여 주세요.
- **회차가 이상해요** → 같은 출강의 제목(출강처·프로그램)이 회차마다 같아야 이어서 셉니다.
- **날씨가 안 나와요** → 설정에서 기본 지역을 정하세요. 출강지는 캘린더 일정의 '장소'가 있으면 그것, 없으면 출강처 이름(예: B초 → B초등학교)으로 찾습니다.
- **서류가 너무 예전 것까지 보여요** → 설정의 "이 날짜부터의 서류만 보기"를 바꾸세요.
