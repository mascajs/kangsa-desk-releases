강사데스크 소개 개인정보처리방침

1. 무료 제공

강사데스크는 무료로 제공되는 개인용 Windows 앱입니다.

2. 있는 그대로 제공

앱은 있는 그대로 제공되며, 일정·서류 마감·날씨 등 표시 내용의 정확성이나 중단 없는 동작을 보장하지 않습니다. 중요한 일정과 마감은 원본(구글 캘린더, 기관 안내)으로 확인해 주세요.

3. 사용자 책임

사용자는 본인의 구글 계정과 PC에 저장된 데이터를 관리할 책임이 있습니다. 데이터 처리 방식은 개인정보처리방침을 따릅니다.

4. 변경과 문의

약관이 바뀌면 이 페이지에 게시합니다. 문의는 GitHub 이슈로 남겨 주세요.
